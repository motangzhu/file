## herdr 教学
- herdr = 终端多路复用器（类 tmux），核心卖点：agent 状态侧栏（blocked/working/done/idle）+ 会话持久化（detach 后进程不死）。
- Windows 版为 beta：`irm https://herdr.dev/install.ps1 | iex`。
- 键位前缀 ctrl+b：c 新标签 / v,- 分屏 / shift+n 新工作区 / w 切工作区 / q detach / ? 全部键位；`herdr server stop` 结束会话。
- 远程三种用法：①ssh 后敲 herdr（堡垒机场景推荐）②`herdr --remote 别名`（配 ~/.ssh/config，瘦客户端）③手机 SSH。
- 前提：herdr 要装在会话真正运行的机器上（Linux/macOS 稳定）；单二进制 ~10MB 可 scp 进内网；生产机安装需先确认合规。
