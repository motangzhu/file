## TKE 集群公网访问连接排查（WSL / 公司电脑）

**背景**：用户公司电脑（WSL Ubuntu）连接 TKE 广州集群（v1.34.1-tke.5），公网+内网访问均已开启。KubeConfig 中 server 为自定义域名 `data.tke.cls-cloude.com`。

**排查链路与关键结论**：
1. `no such host`：自定义域名在公网 DNS（8.8.8.8）无记录 → 内网私有域名，本机无法解析
2. 控制台"访问 IP"实为 CLB 域名 `lb-k26jw15w-bpahj4q7rzkcglw0.clb.gz-tencentclb.com`，nslookup 解析到公网 IP `203.195.143.238`
3. CLB 域名做 SNI 走 443 → TLS 握手 RST（CLB 为 TCP:443 透传，TLS 在 TKE Proxy 终止，证书 `CN=kubernetes-proxy`，SAN 仅含 `127.0.0.1` / `10.113.233.85`，不含公网 IP 和 CLB 域名）
4. 公网 IP 直连可握手（curl -k 返回版本信息），但 kubectl 严格校验报 x509：SAN 不含 203.195.143.238
5. **解决方案**：KubeConfig server 改为 `https://203.195.143.238:443` + `insecure-skip-tls-verify: true` + 删除 `certificate-authority-data`（CA 与 insecure 不能共存，否则报 "specifying a root certificates file with the insecure flag is not allowed"）

**遗留/后续**：
- 当前为临时方案（中风险：跳过 TLS 校验），建议正规化：
  - 首选：公司 VPN/专线接入 VPC，用内网访问版 KubeConfig（server=10.113.233.85，证书匹配，零风险）
  - 次选：公网访问正规化——控制面配置自定义域名证书（SAN 含公网 IP/域名）+ 公司 DNS 加 A 记录 `data.tke.cls-cloude.com → 203.195.143.238`
- API Server 安全组为 `sg-8hjouyp1`（恒信办公网络-安全组），已放通本机出口 IP 183.6.45.131

**复用要点**：TKE 公网访问若走 CLB TCP 透传（非 EIP 直连），服务端证书只对内网地址签发，公网客户端必须跳过校验或配置正规证书。

## QQ 音乐桌面歌词颜色（UI 自动化实战）

**任务**：用户要求直接改 QQ 音乐桌面歌词颜色（默认是青色不好看）。最终通过 UI 自动化在设置 → 桌面歌词 → 色块 → 弹出色板完成。

**关键发现（节省未来工作量）**：
1. **QQ 音乐配置全加密**：`%APPDATA%\Tencent\QQMusic\ConfigInfoXML1.dat`、MMKV、SQLite 数据库都是密文二进制，硬改文件行不通。
2. **设置窗口是 CEF 内嵌**：`pywinauto` UIA 模式只能看到外壳，无法枚举到色块控件；最终走 `pyautogui` + Win32 API 真实点击。
3. **色块位置**（用户主窗口 1100×800 时）：
   - 已播放字色：(808, 442) 16×16
   - 未播放字色：(913, 442) 16×16
   - 边框颜色：(1000, 442) 14×14
4. **取色器"选择图标颜色"窗口特性**：
   - PID 与 QQ 音乐主进程同源（29836）
   - 位置会随点击的色块位置浮动（点色块 A 在 x=623，点色块 C 在 x=718）
   - **没有"确定/取消"按钮**：点击色板或颜色矩阵立即应用
   - 内部只有 26 个预定义色板 + 颜色矩阵 + 色相滑块，**没有 RGB/HEX 输入框**，无法精确设任意色值
5. **色板位置相对 PICKER 起始坐标固定**：第 1 行 y=PICKER.top+160，第 2 行 y=PICKER.top+180；色板第 N 个色块 x=PICKER.left + 28 + (N-1)×20。
6. **取色器不会自动关闭**：必须 `PostMessageW(hwnd, WM_CLOSE=0x0010, 0, 0)` 否则下次操作卡住。

**操作流程**：
1. 最小化 WorkBuddy（避免遮挡），用 `keybd_event(VK_MENU=0x12, DOWN)` + `SetForegroundWindow` 解除前台锁
2. 点击色块 → 枚举找「选择图标颜色」窗口 → 读其 `GetWindowRect` 算色板绝对坐标
3. 点击色板或拖动颜色矩阵
4. `PostMessageW` 关闭 PICKER

**最终配色**（用户壁纸上效果佳）：
- 已播放字色：#009F95（0,159,149）— 深青绿
- 未播放字色：#81EEFE（129,238,254）— 浅青色（保持原色）
- 边框颜色：#009F95（0,159,149）— 深青绿（与已播放同色，让字与描边融为整体）

**复用要点**：QQ 音乐（版本 2260.14.51.32，路径 D:\tools\QQMusic）配置加密 + 取色器无 RGB 输入，UI 自动化是唯一可行路径。色板坐标相对 PICKER 起始固定是核心技巧。

**色板真实布局（重要修正）**：
- 第 1 行 13 个色块连续：`x_offset = 32 + (N-1)*20`，PICKER 起始 x + 32 = 第一个色块
- 第 2 行 **N=5 和 N=6 之间有一个 20px 空位**（不是真色块，是设计留空），所以 N≥6 时偏移要多加 20：
  `x_offset = 32 + (N-1)*20 + (20 if N >= 6 else 0)`
- y_offset：第 1 行 = 160，第 2 行 = 180（相对 PICKER 起始 y）
- 第一次扫描时漏了 N=5 (112, 112, 112) 灰色块（被阈值过滤掉），导致边框 N=9 橄榄色计算偏 20px、点到了 N=8 紫色 — 教训：扫描色板时阈值要放宽，宁可误报

**最终配色**（用户偏好暖色）：
- 已播放字色：#EC6300（落日橙 236,99,0）
- 未播放字色：#D2C0A5（暖米 210,192,165）
- 边框颜色：#44592E（暖橄榄 68,89,46）
